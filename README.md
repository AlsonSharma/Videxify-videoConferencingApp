## 🏁 Getting Started (Local Setup)

1. **Clone Repository**
   ```bash
   git clone https://github.com/AlsonSharma/Videxify-videoConferencingApp.git

2. **Install Dependencies**
**Frontend**
```bash
cd frontend
npm install
```
**Backend**
```bash
cd backend
npm install
```

3. **Configure Environment**
Create .env files using the .env.example templates

4. **Launch Development Servers**
**Backend**
```bash
cd backend && npm run dev
```

**Frontend (in new terminal)**
```bash
cd frontend && npm run dev
```

## 📌 Key Features I Implemented

Feature	Implementation Details

- **Video Calls**	WebRTC peer connections with STUN/TURN
- **Authentication**	JWT with secure HTTP-only cookies
- **Payments	Stripe** integration with test mode
- **Real-time Chat**	Socket.io bidirectional communication
- **UI Components**	Custom MUI theme + responsive design
